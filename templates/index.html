    One file.
    No installer.

    No package manager and no account. Unpack the download, copy the .clap file into ~/.clap and rescan plugins in your DAW.

    Each plugin's page has the full steps: for all users, with a checksum, and to uninstall.

    Who makes these

    About JellyComet

    JellyComet makes small, free audio plugins for Linux. Each does one job with one unusual control: a jellyfish pad for vocal pitch correction, for a reverb's room, for an 808 bass's dirt and for a voice's air, one knob for an optical compressor, rings you hold to hear one band of a tube EQ, an orbiting puck for loop effects, and white keys that play any scale or chord. All are CLAP plugins for x86-64 Linux, MIT-licensed, each with a manual.

    CLAP is an open plugin format that hosts such as Bitwig Studio and REAPER load natively on Linux. Every JellyComet plugin installs by copying one .clap file into ~/.clap.
